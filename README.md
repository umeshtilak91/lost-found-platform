# 🔍 Lost & Found Platform

A web-based Lost & Found platform where users can report lost or found items,
upload images, and securely connect with the person who reported an item.

## 🚀 Features

- Google OAuth authentication
- Report lost/found items
- Upload item images
- Browse lost items
- Browse found items
- View item details
- User profile
- Mobile number/contact privacy settings
- View user's posted items
- Secure authenticated APIs
